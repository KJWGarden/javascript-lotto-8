# javascript-lotto-precourse

## 사용자에게 입력받기

- 구입금액 입력을 받는다
- 구입금액은 1,000원 단위로 입력 받는다
- 1,000원 으로 나누어 떨어지지 않는 경우 예외 처리한다

## 발행한 로또 수량 및 번호 출력하기

- 구입금액 1,000원 단위로 나눠서 구매 횟수 계산하기
- 횟수 만큼 로또 발행하기 (1장당 1,000원)
- 발행한 로또 숫자 오름차순 정렬후 출력하기

## 사용자에게 당첨번호를 입력받기

- 6개의 당첨번호 입력을 받는다
- 번호는 쉼표(,)를 기준으로 구분한다

## 사용자에게 보너스 번호를 입력받기

- 1개의 보너스 번호를 입력 받는다

## 당첨내역 출력하기

- 발행한 로또마다 일치한 숫자 개수를 체크한다
- 당첨 등수별 일치한 로또개수를 출력한다
- 총 당첨금을 계산한다

## 총 수익률 출력하기

- [ ( 당첨금액 / 총 금액 )* 100 = 총 수익률 ]출력하기
